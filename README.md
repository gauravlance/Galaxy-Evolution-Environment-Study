# Galaxy Evolution Environment Study

Course research project examining how cluster environments influence galaxy evolution using optical spectroscopy, optical/NIR imaging, and H I 21 cm observations.

## Overview

This project was completed for PHYS 474 at the University of Waterloo. It reviews observational evidence for differences in galaxy evolution between cluster and field environments, with a primary focus on optical spectroscopy.

The project involved reviewing scientific literature, interpreting observational results, evaluating assumptions and uncertainties, and communicating the findings in a structured scientific report.
